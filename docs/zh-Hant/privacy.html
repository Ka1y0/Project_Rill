Rill 隱私政策

生效日期：2026 年 10 月 5 日。發布者：Kuiyu Fu / Chips Studio。本政策適用於 iPhone 和 iPad 上的 Rill 1.0。

你的裝置與服務

Rill 無需註冊帳號，不營運推論中轉、廣告或分析統計後端。這不代表資料從不離開裝置：你選擇的 AI 服務會處理請求。

API 密鑰保存在本機 iOS 鑰匙圈，不會進入聊天資料庫、搜尋索引或一般匯出檔。Rill 1.0 不啟用 iCloud 鑰匙圈密鑰同步或 CloudKit 聊天同步。既有本機歷史會保留；裝置備份仍由你的系統設定管理。

訊息、分支、草稿、模型身分、回應、設定及附件保存在本機。私有搜尋索引只是可重建的加速層，不參與備份、CloudKit 同步，也不將內容發佈至系統 Spotlight。

何時傳送資訊

首次向已設定接收方請求回答前，Rill 會詢問是否允許傳送聊天內容。請求可能包含目前訊息、活動分支適用的完整原始歷史、系統提示詞、相關圖片或檔案，以及模型所需的協定狀態。群聊中，各模型預設只收到自己適用的歷史，不讀取其他模型的回答。Rill 不會默默裁短歷史或產生有損摘要。

密鑰直接用於向所選服務驗證。接收方也會獲得 IP 位址等一般網路資訊。更新模型目錄時，只傳送列出模型所需的驗證及設定，不傳送聊天正文、草稿、系統提示詞或附件。目錄可按需更新，也可在系統允許時為適用的雲端服務進行機會式更新。

支援設定 OpenAI、Anthropic、Google Gemini、xAI 及自訂 OpenAI 相容端點。各服務的條款、保存期限、訓練控制、帳號關聯與地區限制不同；出現在目錄中不代表已取得推論權限。傳送敏感資料前，請閱讀 AI 服務說明。本機端點是否繼續外傳由其自身決定，Rill 無法控制第三方伺服器的後續處理。

Rill Demo 是裝置上的固定示範，不存取網路、不使用密鑰，也不分析圖片。

權限與可選功能

只有選擇拍攝附件時才請求相機權限。系統照片與檔案選擇器僅提供你選取的項目，Rill 不掃描照片圖庫。區域網路存取只用於你設定的位址。新模型系統通知預設關閉，只有你主動開啟才會使用，不包含聊天正文或密鑰。

Rill 1.0 不啟用朗讀、語音輸入或可執行 HTML 預覽。Markdown、表格和程式碼作為內容顯示，產生的 HTML 不會執行。不含追蹤或廣告 SDK，不請求追蹤許可。

保留與控制

本機歷史保留到主動刪除或移除 App。刪除保護防止晚到工作恢復已刪除聊天；少量刪除記錄可能為資料完整性而保留。匯出檔由你管理。本機刪除不會刪除服務商已處理的資料，請使用其控制與政策。服務設定中撤銷傳送許可會阻止後續請求，不刪除歷史，也不默默取消已有請求。

Rill 不向發布者上傳診斷日誌或聊天；Apple 可依系統設定處理裝置與 App 診斷。支援郵件中，你主動提供的資料會由發布者與郵件服務接收，請勿附上密鑰或不必要的私人聊天。

網站與聯絡

本靜態網站沒有 Cookie、分析指令碼、表單或遠端字型。GitHub Pages 依 GitHub 隱私聲明 提供託管並處理安全日誌。

隱私與支援聯絡：hideinicloud@icloud.com。政策更新會在此標示日期。
