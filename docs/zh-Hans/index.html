Rill

适用于 iPhone 和 iPad 的自带 API Key AI 聊天客户端。

你的模型，一处安静的聊天空间。邀请模型加入私人群聊，把文字与图片一起发送。编辑早先的提问，从新分支继续，不丢失原来的对话。连续阅读长回答，找回旧消息；模型支持时，还可看到消息回应和公开的思考摘要。

无需密钥或网络即可体验 Rill Demo。它是明确标注的本地固定示例，不是真实 AI 模型。Rill 1.0 将聊天和密钥保留在设备上，不提供云同步、语音或可执行 HTML 预览。真实模型服务由你配置，可能另行收费。
