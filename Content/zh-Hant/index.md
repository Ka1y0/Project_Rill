# Rill

適用於 iPhone 與 iPad 的自備 API Key AI 聊天用戶端。

你的模型，一處安靜的聊天空間。邀請模型加入私人群聊，把文字與圖片一起傳送。編輯先前的提問，從新分支繼續，同時保留原來的對話。連續閱讀長回答、找回舊訊息；模型支援時，也能看到訊息回應和公開的思考摘要。

無需密鑰或網路即可體驗 Rill Demo。這是明確標示的本機固定範例，不是真實 AI 模型。Rill 1.0 將聊天和密鑰保留在裝置上，不提供雲端同步、語音或可執行 HTML 預覽。真實模型服務由你設定，可能另外收費。
